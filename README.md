# Dengue and entomological indicators in Juanjuí

Supplementary materials for version 5 of *Association between dengue cases and entomological indicators of Aedes aegypti in a city in the Peruvian Amazon*, by Kepler N. Andrade-Herrera, Alvaro E. Tresierra-Aguilar, and Irwing S. Saldaña. The study covered 770 patients notified with suspected dengue from January through June 2025. The analytical population contained 252 patients, of whom 124 tested positive and 128 tested negative.

## Repository contents

| Folder | Contents |
| --- | --- |
| [Tables](tables/) | Tables 1–3 and S1–S2 from the submitted English version, in CSV format. The [analysis outputs](tables/analysis_outputs/) contain six additional CSV files generated by R. |
| [Figures](figures/) | Figures 1–4 and S1 in PNG and PDF. Figures 2–4 are the submitted English files. |
| [Data](data/) | Aggregated counts for the participant flow, household infestation by test result, and inspection delays, plus the study sector polygons and the [analysis data dictionary](data/data_dictionary.csv). |
| [Code](code/) | Python scripts for preparing data and drawing figures, and an R script for the statistical analysis. |

The public Figure 1 uses the five study sector boundaries from the submitted map. Figure S1 summarizes the delay for all 254 inspected households. The median delay was 2 days (IQR 0–4), and 99.2% of inspections took place within seven days. The public figure groups delays of 5–7 days and reports a pooled total for delays beyond seven days.

## Data and code availability

The analysis code, aggregate data, and supplementary materials are available in this repository. Access to individual surveillance records, which contain clinical information, visit dates, and locations, requires authorization from the Mariscal Cáceres Territorial Health Management Unit. Requests may be directed to the study authors for review with the data custodian.

## Reproduction instructions

Run the following commands from the repository root with Python 3.13. The figure scripts use the public aggregate data and write their outputs to `build/figures/`. Figures 2–4 use Arial, so a fallback font may alter their appearance on other systems.

```bash
python -m pip install -r requirements.txt
python code/29_sector_map.py --output build/figures
python code/33_study_design.py --output build/figures
python code/32_figures.py --output build/figures
```

To rerun the statistical analysis with authorized data, supply the original surveillance workbook. Use R 4.6.1 with `sandwich` 3.1-3, `lmtest` 0.9-40, and `zoo` 1.9-1. The first command writes individual-level records to a local, ignored build directory.

```bash
python code/30_prepare_analysis_data.py "/path/to/authorized-workbook.xlsx" build/private/analysis_data.csv
Rscript --vanilla code/31_analysis.R build/private/analysis_data.csv build/tables
python code/28_aggregate_figure_data.py build/private/analysis_data.csv build/data
```

Compare the six CSV files in `build/tables/` with [tables/analysis_outputs/](tables/analysis_outputs/). The files in `build/data/` reproduce the three public aggregate CSV files in [data/](data/). Table 1 describes the study design and was transcribed from the submission.
